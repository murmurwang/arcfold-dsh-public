# 方法怎样进入下一次工作

模型可见的原件保留完整正文、角色、时间和来源定位；原生模型消息的 `replayState` 只供供应商续接，不能再作为方法依据复制进背景。方法、理解、目标和新冻结学习材料共用此展示规则，原始事件、原生续接数据和已冻结学习输入保持不变。旧理解快照和目标关联仅在新读取副本中更新展示，目标原始关联摘要仍先完整核对。容量检查继续计算全部指导和真实原文，真实正文超限仍拒绝且不消耗试用；没有提高或取消容量限制。

用户纠正助手后，已完成的学习可以保存一条带有原件、适用条件和有限次数的方法。下一次用户委托工作时，程序先提供方法目录；助手判断某条方法适用，再单独调用选择工具。程序核对实际会话、已经展示的版本及剩余次数，保存一次采用并返回回执。只有宿主留下成功的工具结果后，下一步才附入完整指导和依据。文件操作仍由 DSH 执行。

这不是另一个规划或执行循环。目录选择、工具调用和后续行动都在同一个原生主 Agent 中；学习仍使用独立受控会话。方法不能授权新工具、代替当前用户要求或替用户确认长期采用。

## 输入、采用与实际效果

- `context-material.mjs` 按完整条目装入有容量上限的目录，不提前塞入方法正文。明确的用户要求和已完成理解继续按原有路径进入输入。
- `method-tool.mjs` 从实际运行的主 Agent、持久调用、模型可见目录和保存的版本联合确认身份。模型不能自填会话、试用次数或用户确认。包含方法选择和其他行动的整批调用会被拒绝，避免先行动再读取指导。
- `methods.mjs` 在同一事务中检查当前来源、版本、展示范围和全部材料容量，再按原生会话起点及方法版本计次。同轮重复选择不重复计次；两项工作争最后一次名额时只能有一项成功。
- `method-context.mjs` 要求有对应的成功原生工具结果。即使工具失败后宿主仍保留延后插入的背景，也不能据此把方法正文传给模型。
- `session-bridge.mjs` 在后续步骤重新核对来源与内容，替换本插件的旧背景节点；历史原事件、人类原话和工具回执继续保存。交给宿主前核实际输入，受管 DeepSeek 出口还在鉴权和请求证据写盘之后、实际发出之前做同步复核，避免等待期间的撤回漏过早期检查。其他模型出口须单独验证同一边界。`method_inputs` 只证明校验后的材料交给宿主，不证明供应商收到、模型遵守或方法有效。
- 只有读到持久原生轮次结束记录，才登记这次采用的结束状态；正式交付与方法效果分开。失败、取消和结果未核对不自动退还试用次数，避免重发或重复采用。

目录中的剩余次数是展示时的快照，实际领取时重新检查。领取次数不会改变方法内容版本，因此下一轮领取不会让上一轮尚在进行的学习错误失效。学习读取的是该次交付截止时的采用次数，不能借用未来经历。

## 试用结束与用户决定

最后名额被领取时，同一事务保存“名额已领完，部分结果仍待核对”的提醒。当前已领取工作可以继续；新的采用需要决定。没有原生结束记录时，重开网页仍显示该事实及未核对采用，程序不会猜测进程死亡或改写执行结果。真正结束后，按试用次数暂停并保存明确理由。

宿主关闭时，写入者可能先于后台核对结束。已绑定会话若无法再刷盘，桥接保留该错误，并只读核对持久原件；只读结果缺少结束事件时仍不结算，也不拼入内存中的结束记录。整体卸载中连只读操作也失败，则保留待核对状态，等下次恢复。初次绑定与发送前的写盘屏障继续严格执行。

`packages/method-ui` 在 DSH 同一网页的 Arcfold 页签提供方法卡片和详情。同一方法只显示一张卡，以当前状态、停止理由和需要用户决定的事项为主；历史提醒收入详情，默认折叠并可独立翻页。服务先按方法编号合并全部记录，再分页，不按标题合并不同方法，也不因提醒分页而丢失历史。旧暂停提醒不会覆盖当前已经继续采用的状态；原始提醒内容和已读状态仍保留。

打开卡片后，可查看完整指导、适用条件、原始依据、停止理由和未核对采用，选择继续采用或保持暂停。查看详情、翻页或标记已读不等于重新启用。决定绑定当前看到的版本与内容摘要；刷新列表或历史不会悄悄替换正在审阅的全文。内容变化会要求重新查看。重复请求有稳定身份，网络中断后也不会自动生成另一个决定。

继续采用表示用户允许该版本在适用范围内继续使用，不表示其效果已验证。来源撤回、依赖变化、负面反馈或用户暂停仍可阻止后续采用；停止都有保存的原因。正反馈本身不会绕过用户决定自动续期。

网页身份沿用官方 Connection 的已认证浏览器连接。模型工具中没有“用户确认继续”的接口。这是应用内入口分工，不能对拥有同一本机文件和浏览器权限的代码宣称独立的真人身份认证。

## 装配与验证边界

业务插件提供 `arcfoldMethods`；仅主会话 preset 装配 `@arcfold/dsh/agent` 及其方法选择工具；网页单独装配 `packages/method-ui/src/index.mjs`。UI 使用独立包名 `@arcfold/dsh-method-ui`，避免根包多个入口争用同一浏览器模块来源。构建命令为 `node packages/method-ui/build.mjs`。

本增量仍在统一验证。覆盖业务计次、旧轮学习时间边界、成功工具回执、失效材料移出、真实官方网页请求解析及显示的检查，不代替官方宿主全流程、浏览器点击或真实模型效果证据。完整产品还需长期目标与执行关联、其余网页迁移、安装打包和实际内容验收。
