# 0.5.1 随包许可修补

0.5.0 的原生模型配置代码已经合入。发布前发现精简 Python 包缺少底层库声明，分词 wheel 的依赖声明也不完整，因此按已确认决策补齐后发布 0.5.1；0.5.0 保留为未公开候选。对齐时的原始决策见 [release-license-notices.md](notes/release-license-notices.md)，正文不回写为事后结论。

```mermaid
flowchart LR
  A[锁定的 Python 与分词器原包] --> B[对照构建清单和依赖清单]
  B --> C[从对应上游取得许可、版权和源码链接]
  C --> D[组件清单记录原路径、来源和摘要]
  D --> E[打包前核对，再解开实际安装包核对]
  E --> F[任何已核对材料缺失或改变则停止构建]
```

本次只增加发行材料、打包校验及版本记录。模型选择、提示词、凭据、历史资料和后台行为不变，不新增模型调用。

## 证据与边界

- Python 原包仍为 `81a359f1cfadd4da11766534c5913791cea55f26e1bb902cacd2a531bb1e4b2b`。许可取自同版本同目标的完整构建 `dbefa04d4107b449e17022f9c78d3eacbd37a1aa8c166c6220dbd95addf3f318`。按其中的扩展模块许可路径逐项关联，保留 19 份原文。缺少的 zlib-ng 路径有系统 zlib 链接证据，未伪造该许可文件。
- 分词 wheel 仍为 `624bb4d0fb3ed541b9e34d2ef96ff66057026ded7d6708b0b9088cc6d6723999`。依赖清单含 332 项：327 项 crates.io 源码归档按清单摘要核对，5 项 DeepSeek 自有组件由 wheel MIT 许可覆盖。根组件另行记录。该清单覆盖所有平台，不能当作 macOS 实际链接清单。
- r-efi 的完整许可位于 AUTHORS；8 项其他组件从对应上游补足，来源依据逐项保留。option-ext 的 MPL-2.0 许可和未修改源码下载信息随包保留。
- 分词器二进制还包含 Rust 编译器提交信息，对应上游 1.97.1。标准库的声明从该版本官方发行包取得，包含标准库及其依赖的版权说明。
- 核心包携带上述材料；界面包使用宿主 React，不把 React 实现代码打入包。npm 另行下载的依赖仍使用各自的许可，本次没有把它们重打进 Arcfold 归档，也不宣称完成所有 npm 依赖的法律审查。

## 可复核入口

- `src/desktop/third-party/manifest.json`：来源地址、版本、原始路径、来源摘要和对应声明；同目录 README 提供可读索引。
- `scripts/package-release.mjs` 的 `validateThirdPartyNotices()`：在打包前和解包后验证已审阅清单及材料，没有在线下载或模型请求。
- `test/package-release-desktop.test.mjs`：在真实构建的安装包中，分别移除、改坏 Python、Cargo、wheel 和 Rust 声明，再删减组件清单，确认均拒绝；恢复原文后重新通过。
- 锁文件只更新本项目版本；依赖版本、下载地址和完整性摘要保持不变。两份包均为 0.5.1。

自动测试、独立审阅、两次构建和隔离账户验收分别由交付入口保存回执；这些结果不由本说明预先宣称。实际 npm/GitHub 公开包须与最后验收的归档逐字节一致。真实模型效果及开发者日常使用反馈仍另行记录。
