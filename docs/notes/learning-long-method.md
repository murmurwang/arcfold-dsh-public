# 每轮学习保存完整方法

用户本轮明确要求以后沿用一套多步做法，且流程原文出现在本轮或学习输入已有的上一轮时，学习可产出完整方法。提示词要求保留原步骤与顺序，同时引用沿用要求及流程原文；一次性指令不形成方法。

`experience-v1` 的 method 接受 short 与 long，至少一个非空。long 复用已有方法格式：name 最多 80 字，description 最多 60 字，whenToUse、steps、pitfalls、verify 合计最多 2000 字。旧的平铺短规则仍兼容。每轮仍最多一个方法，无新增模型调用。

程序核对本轮用户来源和文字限制；内容是否确实表达以后沿用、步骤是否忠于原文，由学习提示词约束，不能把格式检查当作语义效果验证。方法被拒不影响同轮其他认识，并保存拒绝原因。

通过既有登记入口保存到 tree_methods，目录只展示名称和描述，arcfold_read_method 返回完整 long。相关测试覆盖双版本、仅长版、空方法、超长、缺少用户来源、跨轮引用、目录与实际工具读回。
