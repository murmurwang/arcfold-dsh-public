# Agent Note: 提供可在 DSH Desktop 按包名安装和更新的 Arcfold 归档

Status: proposed

## Problem

当前仓库已有 Desktop 插件代码，打包入口仍缺失。首发要让用户在 DSH 的「添加插件」输入一个包名，随后从插件页选择更新。核心包和界面包须作为同一版本安装。此前试验中，Desktop 用不到的 OpenAI 适配器依赖触发了额外的依赖脚本批准提示。

## Proposal

增加 Desktop 构建命令，从固定的 Git 提交和与锁文件相符的依赖生成两个归档。核心包依赖同版界面包。归档带上安装与更新说明、许可证和第三方声明。当前 Desktop 构建去掉未用的 OpenAI 适配器，保留固定 DSH 宿主及其 DeepSeek 集成。

## Expected outcome

生成可检查来源和内容的两个同版归档。从可访问的软件包源安装核心包时，DSH 同时取得匹配的界面。用户可在插件页看到下一版，并自行选择何时更新。

## Alternatives considered

- 把当前本机工作目录整体放进仓库。首发所需 Desktop 源码已在现有主分支，可以只补构建入口。
- 保留 Desktop 用不到的适配器。该依赖增加了首装提示，当前支持的 Desktop 模型无需它。

## Acceptance criteria

- 通过当前仓库的 Desktop 检查与新增打包检查，整个检查使用与锁文件匹配的冻结依赖。
- 生成两套递增测试版本，核对核心与界面版本、归档内容、许可证和来源。
- 用相同的归档在 DSH 插件页完成按包名安装、用户选择更新和重启读回。

## Risks

测试针对 Apple silicon 的 DSH 0.2.2-rc.1。独立审阅、正式软件包源、完整对话、实际写入的会话正文及首次设置失败时的提示仍待验收。当前候选从本机测试源验证。
