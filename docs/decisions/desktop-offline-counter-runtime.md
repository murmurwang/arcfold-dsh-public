# Agent Note: 在 Desktop 安装包内提供离线计数环境

Status: proposed

## Problem

首发草稿 #8 使用 DSH 0.2.2-rc.1 自带的 Python 运行发送前的精确文本计数。实际用这份程序加载固定的计数库时，macOS 因签名团队不同而拒绝加载。两种受支持模型的合成输入均在发出请求前失败。

## Proposal

将固定版本的 Python Build Standalone 原包作为明确的 Desktop 构建输入。核心包保留原包及其许可。首次设置和重启从插件包解出校验过的计数程序，存放在此 DSH 用户目录下，按原包摘要复用。对已设置的试用环境，原始配置与账本继续用于鉴定数据和费用授权，运行时只换计数程序。

## Expected outcome

用户从 DSH 按名安装后，离线计数所需的程序已经包括在安装内。发送仍要求精确计数。重启和更新能读取既有数据与费用记录。

## Alternatives considered

- 继续用 DSH 自带 Python。两种模型的确切输入都复现了计数库无法加载。
- 要求用户另装 Python。日常安装会多出一个应用外的设置步骤。
- 在计数失败后用估算发送。这会改变现有的发送和计费规则。

## Acceptance criteria

- 固定来自上游原包的地址、大小和摘要。从新建成的安装包取出文件，用两个固定模型输入得到与此前相同的计数。
- 计数资源缺失或内容被改动时明确失败。更新现有试用配置只更换计数程序，保留原始配置文件、账本和用户标识。
- 完成使用本机合成模型的发送与账本演练。原版 DSH 图形界面的安装、更新和重启读回单独验证。

## Risks

Apple 芯片 Mac 的核心安装包新增约 25 MB 的压缩文件。首发前要核查第三方许可证、正式软件包源的传输和普通账户的更新场景。
