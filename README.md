# Arcfold for DSH Desktop（开发候选）

Arcfold 在 DSH Desktop 中提供目标与长期协作界面。当前版本为迁移中的开发候选，尚未完成公开发布及真实模型连接验收。

首次设置会创建独立的数据与工作区，不会自动导入已有版本的数据。DeepSeek 密钥使用 DSH 模型设置和凭据服务；主对话使用 DSH 的模型选择器，与当前对话关联的后台处理跟随该对话选择的模型，后台任务保留各自的思考设置。其他模型提供商尚未完成接入。模型调用产生的费用以服务商为准。

当前测试面向 macOS Apple Silicon、DSH 0.2.2-rc.1、Node.js 24.15 和 Python 3.12。安装、更新、回退和模型费用说明尚待最终验收。开发和离线检查见 [参与开发](CONTRIBUTING.md)。
