# Arcfold for DSH Desktop（开发候选）

Arcfold 在 DSH Desktop 中提供目标与长期协作界面。当前版本为迁移中的开发候选，尚未完成公开发布及真实模型连接验收。

首次设置会创建独立的数据与工作区。候选 0.5.1 复用 DSH 的模型设置、凭据服务和聊天模型列表；主回答及相关后台处理都继承该轮选择的模型和思考强度。进行中换模型从下一轮生效，已登记任务继续使用来源选择。后台保留各自的提示词、权限和输出上限。

从 0.4.x 更新时，确认使用原生模型通道后继续使用原有数据，旧费用记录原样保留。其他版本的数据不会自动导入。调用只记录服务商返回的用量；缺失用量或价格记为未知，不自动重发结果未知的请求。实际费用以所选服务商为准。原生连接的离线模拟不代表已验证任意模型的实际效果。机制与检查范围见 [模型配置途径](docs/native-model-configuration.md)。

当前测试面向 macOS Apple Silicon、DSH 0.2.2-rc.1 和 Node.js 24.15。原生模型调用不需要 Python；旧实验和兼容检查仍使用随包计数环境。安装、更新和真实模型效果尚待最终验收。开发和离线检查见 [参与开发](CONTRIBUTING.md)。
