# 从普通协作中学习

- 学习不再只记用户的明确纠正。每轮最多记 3 条关于用户和这件事的理解，标明用户表达、助手推断或尚不清楚；最多 2 条对已有理解的更正；用户直接提出以后的做法时记成一条短规则，下一轮起自动用于回答。
- 检验按实际效果修正已学内容，可以改写、作废、移动、上提、降回、合并、撤回或加提醒；方法卡片显示检验结果。用户确认或修改过的内容不会被自动改动。
- 整理在离开超时和事项完成时可以把内容提到上级；事项完成时回看做法，把值得沿用的放到上一级。
- 改进根据同一环节反复出现的修正，补充该环节的说明或调整设置。
- 修复从纠正学到的方法无法在目标树中修改的问题。

升级注意：数据库结构不变。升级前已排队或已完成的检验、整理、改进任务仍只写报告，新任务使用新规则。
